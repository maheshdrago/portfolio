# Mahesh Reddy Changal Portfolio

Personal portfolio built with Next.js, TypeScript, Tailwind CSS, and Framer Motion.

## Focus Areas

- Production RAG and agentic AI systems
- Full-stack application development
- Cloud-native and data engineering platforms
- Backend and distributed systems

## Tech Stack

- Next.js 14
- React 18
- TypeScript
- Tailwind CSS
- Framer Motion

## Run Locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run start
```
